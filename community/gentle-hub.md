# Gentle Hub discovery checklist

The full extension must be published before opting in. No catalog listing is claimed.

1. On the public [keepgoing repository](https://github.com/julianbruno/keepgoing), edit **About → Topics**, add `gentle-hub-project`, and save. This is the general project category: keepgoing is an extension for stock Pi.
2. Confirm the topic is visible under **About**. The [Hub joining instructions](https://gentlemanprogramming.com/gentle-hub/#join) use repository topics for opt-in; there is no pull request or submission form.
3. To check discovery, look for `keepgoing` in the [Gentle Hub](https://gentlemanprogramming.com/gentle-hub/) project listing and confirm the entry links to `julianbruno/keepgoing`. If it is absent, recheck the repository visibility and topic spelling, then check the Hub again later.

There is no guaranteed indexing time. A listing helps people find the source; it does not imply endorsement, Gentle Shell compatibility, or publication on npm.
